## 阅读与维护约定

- 使用行为以专题文档和当前源码为准；API 字段查 [API 文档](API.md)，职责归属查[主题边界规范](theme-boundaries.md)。规划或历史方案中的目标、旧路径和示例不代表当前实现。
- “已实现”表示源码已有相应能力；自动化通过、视觉验收和平台实机验收分别记录。历史测试结果不代表本次验证。
- 行为变化同步对应专题文档和 README 概述；新增文档加入本索引，优先交叉链接，避免重复维护完整说明。
- 实施方案保留原步骤与设计背景，入口注明适用状态；继续开发前先对照源码复核，不直接重放旧修改步骤。
