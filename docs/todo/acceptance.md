## 独立跟进的边界缺陷

| 涉及功能 | 对应缺陷 | 修复时回归 |
| --- | --- | --- |
| 1.3 Gapless | 9.1 解码取消可能丢失唤醒；9.9 切设备丢预加载及过期事件重播 | 满缓冲取消／退出、输出设备切换、过期边界事件 |
| 1.4 ReplayGain | 分析线程使用同一 `PcmDecoder`，9.1 可能使取消／析构卡死 | 满缓冲时取消分析、退出等待与资源释放 |
| 1.6 Crossfade | 9.2 尾部 0／1 帧故障已实测；另受 9.1、9.9 影响 | 迟到预加载的 0／1／2 帧边界、有限输出、无重复身份切换、取消与设备切换 |

解码取消问题来自本次源码复核：`PcmDecoder::cancel()` 在未持有等待谓词互斥锁时置位并通知，存在检查谓词与进入等待之间丢失通知的窗口；本次未强制复现该线程竞态。

Crossfade 补充探针直接链接当前构建库，生成两首各 100 帧的 48 kHz 双声道 WAV。先调用 `releasePlanWait()`，渲染当前曲的前 99／100 帧，再预加载下一首、授权 1 ms Crossfade，继续渲染：

- 剩 1 帧：输出 `-nan`，探针检测非有限值后退出码 1。
- 剩 0 帧：进程崩溃，退出码 139。
- 探针、源码与截图留在本地 `build/todo-crossfade-probe*`、`build/todo-acceptance-images*`；它们是忽略的本地验证产物，不属于仓库回归用例。

上述边界未通过，相关功能仍按用户确认的日常可用标准放行；后续修复应把该场景加入正式测试。
