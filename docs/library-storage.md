# 自包含音乐库

导入成功意味着音频及可读取的同名歌词、封面已独立保存。整个文件的 SHA-256 识别音频对象；歌曲 ID 负责收藏、歌单和播放历史。相同字节的多个来源可共享文件，不自动合并不同版本或已有歌曲记录。

## 数据布局与所有权

根目录沿用 `~/Music/NekoTune` 或 `NEKOTUNE_HOME`。数据库沿用 `config/nekotune.sqlite3` 或 `NEKOTUNE_DB_PATH`；库内资源关联使用相对路径，配置和密钥库行为不变。

- `media/<prefix>/<sha256>.<ext>`：不可变音频副本，不写入新的内嵌标签。
- `artwork/<prefix>/<sha256>.<ext>`：校验过的 JPEG、PNG、WebP 封面。
- `song_assets`：歌曲与音频、封面的关联；`song_lyrics`：本地／已选择歌词文档及原始 KRC。
- `.staging/`：导入、下载和恢复暂存；发布及清理日志使重启后的处理可以确定原操作阶段。
- `.rollback/<id>/`：恢复前的媒体目录和操作清单；数据库回退文件保存在原数据库旁，兼容独立数据库路径。

删除歌曲默认界面会请求清理托管文件，API 默认保留。对象存在其他引用，或曾明确要求保留时，不会随另一首歌曲删除。无论哪种情况都不删除外部导入源。歌曲删除不清除历史记录已有的显示快照。

## 升级迁移

首次遇到旧记录先保存数据库快照，然后逐曲复制实际音频、核对旧哈希并收取配套资料。建立新关联后才清理旧编号真实文件、软链接或引用文档；旧目录中的无关文件保留。旧数据库快照用于核对和故障恢复，不保证旧版程序能直接读取已完成新布局迁移的目录。

“设置 → 音乐库”显示待迁移数量及逐曲错误，可重复执行迁移。断链、离线、源内容变化、无效或不可读取的配套资料都会保留原记录和旧文件。恢复可读取的原文件后重试；当前正在使用的旧音频须释放后才能清理。没有完整迁移的外部引用时拒绝整库备份。

增量扫描只检查已登记资源，并补全已知歌曲的缺失时长。完整校验检查全部登记音频和封面。任意文件放到音乐根目录不再自动入库，必须通过导入入口明确添加。

## 导出

曲库导出选中歌曲；歌单导出按歌单顺序，并生成相对路径 `playlist.m3u8`。每次使用新目录，文件名由当前歌手和歌名生成，处理非法字符、保留设备名、长度和大小写重名。原音频字节不变，不改写内嵌标签或转码。

导入会收取同名 KRC、LRC、TXT 及封面；多个封面均保存，未选中的版本作为保留对象备份。同步歌词导出 LRC，逐字歌词保留原始 KRC；只有解析文本时生成压缩 KRC，纯文本导出 TXT，封面与音频同名。缺失或纯在线歌曲不下载，列入跳过结果。结果包含成功、跳过、失败数量、输出路径和逐项错误。

## 目录备份与恢复

备份目录包含 `library.sqlite`、`media/`、`artwork/` 和 `manifest.json`。清单版本为 1，登记每个文件的相对路径、大小和 SHA-256，以及明确缺失的音频对象。存在数据库中的原始 KRC、选定歌词、歌单、队列、标签、历史和在线记录均在快照内。账号、插件、偏好、运行任务、旧目录清理记录和可重建缓存不进入备份。

备份时可继续播放。资源删除受保护；数据库快照之后的新写入不进入本次备份。临时备份目录在复制与校验全部成功后发布，未完成目录不能作为有效备份恢复。应当存在的文件损坏或丢失导致失败；已标记缺失的音频在摘要中列出。

恢复先进行完整预览校验，确认替换后再次校验并复制到目标磁盘。切换前停止播放和后台服务、关闭 SQLite；恢复日志记录每一步旧文件保留与新文件安装。成功后自动重建后端会话，前端重连，播放保持停止。中断的切换在下次启动时回退；已经完成的安装通过数据库检查后继续使用。恢复不合并两个曲库，也不替换设置和密钥。

原曲库副本保留，设置页可显式清理。保留副本占用磁盘空间；外置数据库的副本保存在数据库所在磁盘。不要手动删除恢复日志或在程序运行时覆盖数据库。普通搬家建议使用应用备份／恢复，或完全退出后复制音乐库及显式指定的外部数据库。

## 验证

核心回归入口：

```sh
cmake --build build -j 4
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
ctest --test-dir build --output-on-failure
pnpm --dir extensions test
```

测试使用临时根目录和独立数据库，覆盖副本独立性、资源共享、原文件保护、SQL 失败、中断恢复、备份篡改与越界路径、迁移失败保留资料、导出字节一致，以及真实 IPC 的备份／预览／恢复／重连流程。Windows 文件占用与不同文件系统行为仍需在对应平台运行这些测试，不能以 Linux 通过代替原生验收。
